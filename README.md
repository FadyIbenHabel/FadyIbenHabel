## 🚀 Selected builds

### 🔎 [Traceboard — Evidence-first AI debugging](https://github.com/FadyIbenHabel/traceboard)

An AI-assisted debugging workspace that turns bug reports, source files, and logs into **ranked hypotheses with line-level evidence**. Includes a reproducible no-key demo and optional live LLM investigation.

![Traceboard app showing an investigation with ranked hypotheses and source evidence](https://raw.githubusercontent.com/FadyIbenHabel/traceboard/main/docs/images/workspace.png)

`TypeScript` · `React` · `BM25` · `Cloudflare Workers` · `Groq (optional)`

**[Explore the repository →](https://github.com/FadyIbenHabel/traceboard)**

### ⚽ [Footence — Football intelligence](https://github.com/FadyIbenHabel/footence-demo)

My passion project at the intersection of **data science and football**. Explore how teams build attacks and create chances, compare them with the right peers, and follow the recorded events behind each insight.

![Footence product preview showing a football intelligence dashboard and tactical evidence](https://raw.githubusercontent.com/FadyIbenHabel/footence-demo/main/assets/branding/github-hero.png)

`Python` · `FastAPI` · `React` · `TypeScript` · `Sports Analytics`

**[Project showcase →](https://github.com/FadyIbenHabel/footence-demo)** · **[Watch the demo 🎬](https://github.com/FadyIbenHabel/footence-demo/blob/main/assets/video/footence-linkedin-32s.mp4)**
