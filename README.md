### Featured projects

**[Traceboard — Evidence-first debugging assistant](https://github.com/FadyIbenHabel/traceboard)**  
Turns bug reports, code, and logs into inspectable debugging briefs. Uses source retrieval, ranked hypotheses, validated line-level citations, and concrete next-step checks. Includes a reproducible no-key demo and optional live LLM analysis.  
`TypeScript` · `React` · `BM25` · `Groq` · `Cloudflare Workers`

**[Footence — Football intelligence platform](https://github.com/FadyIbenHabel/footence-demo)**  
An independent project exploring how football teams build attacks and create chances. Combines tactical benchmarks, event-level sequence exploration, and evidence-backed visualizations. The public repository includes a demo and screenshots; the analytical implementation is private.  
`Python` · `FastAPI` · `React` · `TypeScript` · `Sports Analytics`

**[CNRS-GPT V2 — Research document assistant](https://github.com/FadyIbenHabel/cnrsgpt-demo-v2)**  
A RAG prototype for asking questions over academic PDFs, combining embedding-based retrieval, MongoDB Atlas Vector Search, and LLM-generated answers.  
`Python` · `Flask` · `MongoDB Atlas` · `RAG` · `Groq`

**[Neo4j Modular Decomposition Plugin](https://github.com/FadyIbenHabel/neo4j-md-plugin)**  
A Java plugin that adds graph modular decomposition to Neo4j through a callable procedure, using a linear-time algorithm.  
`Java` · `Neo4j` · `Graph Algorithms`
